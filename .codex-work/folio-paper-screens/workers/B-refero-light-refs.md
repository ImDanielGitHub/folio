## 1. Top 5 Refero screens

### 1) Claude — new chat home  
**UUID:** `13fe0c11-f8aa-4100-b81c-511b5f4cd2e6`  
**Product:** Claude (claude.ai)  
**Refero:** https://refero.design/pages/13fe0c11-f8aa-4100-b81c-511b5f4cd2e6  

**Why it fits Folio**  
Best match for Folio’s *default* state: conversation is the entire product. Soft mineral ground, centered reading/composer column, almost no permanent chrome, and Artifacts framed as an optional summoned surface—not a home dashboard.

**Clone structurally**
- Single calm composition: greeting → one composer → optional starter prompts
- Extremely low chrome density; history tucked away
- Fixed, unhurried composer as the only persistent control
- Wide breathing room; content reads as a gallery placard, not an admin console

**Do NOT clone (brand / colour)**
- Claude wordmark, serif greeting voice, anthropomorphic tone
- Soft lavender “NEW Artifacts” banner / purple product chips
- Exact beige `#F3F1E9` / clay `#D27A5E` pairing if it drifts into cream×terracotta marketing cliché
- Plan-upgrade chrome in the hero

**Refero:** https://refero.design/pages/91a5de25-6006-4b3c-94f2-7c8f8df47a90

## 3. Folio light token proposal

Aligned to recovered Paper lock; nudged toward chalky mineral / gallery calm. Prefer plaster `#F4F4F1` and ink `#171A18` over cream×terracotta cliché. Copper is CTA/focus only—not decoration.

```css
:root {
  color-scheme: light;

  /* Surfaces — chalky mineral */
  --bg: #F4F4F1;           /* plaster ground (app shell) */
  --rail: #EFEFEB;         /* quiet rail, one step cooler than ground */
  --thread: #FBFBF9;       /* reading column / conversation plane */
  --canvas-bg: #F1F1EE;    /* summoned finance/document surface */
  --panel: #FFFFFF;        /* drawers, composer fill, source cards */
  --divider: #E4E4DF;      /* hairline only */

  /* Ink */
  --text: #171A18;         /* primary ink */
  --text-soft: #3F433F;    /* secondary prose */
  --muted: #6B6F6A;        /* meta, citations, timestamps */

  /* Accent — burnt copper (brand / focus / primary action only) */
  --accent: #C96642;
  --accent-soft: #E8D2C6;  /* focus ring / soft selection */

  /* Semantic (meaning only; never chrome decoration) */
  --positive: #397756;
  --warning: #9B6B27;
  --negative: #A5483D;

  /* Elevation — restrained */
  --shadow-composer: 0 1px 2px rgba(23, 26, 24, 0.06),
                     0 8px 24px rgba(23, 26, 24, 0.04);
}
```

**Type:** Instrument Sans / Aptos / system sans for prose and numerals. No Inter-as-brand, no purple gradients, no glow.

**Role rules**
- Conversation lives on `--thread` over `--bg`; rail never competes with ink.
- Canvas uses `--canvas-bg` + `--panel` for the artifact; closes cleanly back to thread-only.
- Evidence drawer = `--panel` over thread; citations use `--muted` until opened.
- `--accent` = send / primary owner action / focus ring only.

## 4. Clone-quality checklist (Paper Folio ↔ Refero structure)

Use when comparing Paper Folio artboards to the screens above. Pass = structural kinship; fail = dashboard / dark / purple drift.

### Composition
- [ ] Default state is chat-only (rail + thread + composer)—no permanent canvas, evidence browser, or KPI wall
- [ ] Reading column feels centered/constrained (~≤760px), not full-bleed admin width
- [ ] When canvas opens: same thread persists; canvas is sibling, not a navigation destination
- [ ] Canvas has an obvious close; closing does not leave the conversation
- [ ] Narrow view: Thread | Finance as panes/tabs—not a squeezed three-zone dashboard

### Chrome density
- [ ] Rail ≈ infrequent utilities only (Sources / Activity / Privacy)—not a full product sitemap
- [ ] No top command bar of finance tools competing with the answer
- [ ] Dividers are hairline; elevation is composer/drawer only
- [ ] Zero purple glow, indigo AI gradients, or dark ops panels

### Composer
- [ ] Fixed/calm bottom composer always available in thread
- [ ] One primary send action in copper; attach secondary
- [ ] Composer stays with the conversation when canvas is open
- [ ] Placeholder/copy is owner-plain, not chatbot-cute

### Canvas (summoned)
- [ ] One current surface (chart / txn / invoice / records / scenario / owner pack)
- [ ] Header: title + close + minimal utilities (not a toolbar farm)
- [ ] Content reads as a document/instrument, not a dashboard of cards
- [ ] Resize/focus allowed; empty state is closed, not a placeholder grid

### Evidence
- [ ] Default answer shows a compact “Based on N linked sources” affordance
- [ ] Full evidence is a drawer/panel, not a permanent third column
- [ ] Source rows: human name + short description/excerpt; raw IDs nested
- [ ] Closing evidence returns to the same scroll position in the thread

### Spacing & type
- [ ] Generous vertical rhythm between turns; no dense chat-bubble stack
- [ ] Ink on plaster contrast holds for vault numbers and long answers
- [ ] Accent appears ≤1 primary control per viewport region
- [ ] Feels gallery-calm next to Claude home + Gemini sources + ChatGPT canvas—not Hermes, not purple SaaS

### Mood lock (visual)
- [ ] Ground reads `#F4F4F1` plaster, not warm cream brochure
- [ ] Ink reads near `#171A18`, not soft gray-on-cream
- [ ] Copper `#C96642` is the only brand accent
- [ ] Screenshot still looks Folio after stripping any Refero product logos
